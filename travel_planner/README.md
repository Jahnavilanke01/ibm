# AI Travel Planner — IBM watsonx.ai + Flask

A full-stack AI-powered travel itinerary generator built with **Python Flask** and **IBM watsonx.ai Granite LLM**.

---

## Features

- Personalised day-by-day itineraries generated by IBM Granite-13B
- Responsive UI — works on desktop, tablet, and mobile
- Interest chips, budget selector, travel-style selector, traveler type
- Loading animation with step-by-step progress
- Copy itinerary to clipboard
- Quick-select popular destinations

## Quick Start

### 1. Clone & install dependencies

```bash
cd travel_planner
python -m venv venv
# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate

pip install -r requirements.txt
```

### 2. Configure IBM watsonx.ai credentials

```bash
cp .env.example .env
```

Edit `.env` and fill in:

| Variable | Where to get it |
|---|---|
| `WATSONX_API_KEY` | IBM Cloud → Manage → API keys |
| `WATSONX_URL` | Your watsonx.ai service URL (e.g. `https://us-south.ml.cloud.ibm.com`) |
| `WATSONX_PROJECT_ID` | watsonx.ai → Projects → your project → Manage → General |

### 3. Run the app

```bash
python app.py
```

Open [http://localhost:5000](http://localhost:5000) in your browser.

## Production Deployment

```bash
gunicorn -w 2 -b 0.0.0.0:5000 app:app
```

## IBM Granite Model

The app uses `ibm/granite-13b-instruct-v2`. You can switch to another model by changing `GRANITE_MODEL_ID` in [`app.py`](app.py).

Available alternatives:
- `ibm/granite-3-8b-instruct`
- `ibm/granite-20b-multilingual`
